## Features

- **Home:** Introduction with project showcase
- **About:** Interactive experience overview with selectable roles and a companion selector for bonus stats
- **Projects:** Featured projects, including a mix of personal projects and production sites
- **Design System:** Custom CSS variable tokens for a consistent dark theme across all components
- **Responsive:** Mobile-first layout that adapts to wider screens
- **Accessible:** Semantic HTML with `aria-pressed`, `aria-label`, and keyboard-navigable interactive elements
